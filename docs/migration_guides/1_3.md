# Migrating Python agents to LiveKit Agents 1.3

This guide summarizes the structural changes you need to make for 1.3.

## What changed conceptually
- **AgentServer replaces Worker**: wrap your app in `AgentServer`, define entrypoints with `@server.rtc_session`, and start via `cli.run_app(server)`.
- **Build STT/LLM/TTS inside the rtc session**: construct inference plugins after the job context exists, not in `Agent.__init__`; this avoids missing-session/timeouts.
- **Process-level setup for shared assets**: preload VAD or other heavy resources once per process via `server.setup_fnc` and read them from `ctx.proc.userdata`.
- **Session lifecycle**: start the session and then `await ctx.connect()` inside the rtc handler so the room bind happens with full context.
- **Lightweight agents**: keep `Agent.__init__` to instructions/tools; inject models/VAD through `AgentSession`.
- **Optional latency tweaks**: `preemptive_generation=True`, `tts.prewarm()` to warm the websocket, and `ctx.log_context_fields` for structured logs.

## Step-by-step
1) **Wrap with `AgentServer`**
   ```python
   from livekit.agents import AgentServer, cli
   server = AgentServer()

   if __name__ == "__main__":
       cli.run_app(server)
   ```

2) **(Optional) Process setup for shared resources**
   ```python
   from livekit.agents import JobProcess

   def prewarm(proc: JobProcess):
       proc.userdata["vad"] = silero.VAD.load()

   server.setup_fnc = prewarm
   ```

3) **Define the rtc session entrypoint**
   ```python
   from livekit.agents import JobContext, AgentSession, inference

   @server.rtc_session()
   async def entrypoint(ctx: JobContext):
       ctx.log_context_fields = {"room": ctx.room.name}  # optional logging context

       session = AgentSession(
           stt=inference.STT(model="assemblyai/universal-streaming", language="en"),
           llm=inference.LLM(model="openai/gpt-4.1-mini"),
           tts=inference.TTS(model="cartesia/sonic-3", voice="..."),
           vad=ctx.proc.userdata.get("vad"),
           preemptive_generation=True,
       )

       agent = MyAgent()  # keep agent lightweight
       if hasattr(session.tts, "prewarm"):
           session.tts.prewarm()

       await session.start(agent=agent, room=ctx.room)
       await ctx.connect()
   ```

4) **Keep the agent class minimal**
   ```python
   from livekit.agents import Agent

   class MyAgent(Agent):
       def __init__(self):
           super().__init__(instructions="You are a helpful agent.")
       async def on_enter(self):
           self.session.generate_reply()
   ```

## Quick checklist
- Replace `WorkerOptions(entrypoint_fnc=...)` with `AgentServer` + `@server.rtc_session`.
- Move STT/LLM/TTS creation into the rtc session handler.
- Use `setup_fnc` + `ctx.proc.userdata` for shared assets (e.g., VAD).
- Call `session.start(...); await ctx.connect()` inside the rtc handler.
- Keep `Agent.__init__` light (instructions/tools only).
- Optional: `preemptive_generation=True`, `tts.prewarm()`, `ctx.log_context_fields` for better latency and logs.
